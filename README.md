# Гакыйдә курсы

Татар телендәге онлайн-курс автор дәреслеге «Гакыйдә. Җиңел юл белән аңлау һәм өйрәнү» белән бергә эшләү өчен төзелгән. Ул китапны кабатламый: уку юлын, укырга тиешле битләрне һәм автоматик тикшерелә торган тестларны күрсәтә.

- 2 нче һәм 3 нче курслар
- 50 дәрес һәм 528 автоматик бирем
- һәр дәрес өчен дәреслек битләре
- 19–24 нче дәресләр өчен 100 сайлап җавап бирелә торган яңа бирем
- курс һәм дәрес күрсәтелгән аерым укучы сылтамалары
- укучының җирле алга китеш күрсәткече
- Supabase-та саклана торган ябык укытучы журналы

## Нәтиҗәләр

Нәтиҗәләр `aqida_quiz_attempts` ябык таблицасында саклана. Браузер таблицага турыдан-туры керми: яздыру һәм уку `submit-aqida-quiz` функциясе аша башкарыла. Журналны уку өчен `TEACHER_PIN` сере кирәк.

Укытучы журналы `dist/teacher.html` битендә урнашкан.
